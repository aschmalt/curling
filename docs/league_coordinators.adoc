== Purpose

This document defines the standard Evergreen Curling Club process for creating and managing league sessions within SportsEngine.

The goals of this guide are:

* Ensure all league coordinators use a consistent workflow.
* Protect historical rosters, schedules, standings, and team records.
* Provide a repeatable process for creating new seasons.
* Ensure all registered participants are properly rostered.
* Establish a standardized schedule upload process.
* Serve as training material for new league coordinators.

This guide covers:

* Registration verification
* Season creation
* Subseason creation
* Division creation (Tuesday Only)
* Team creation
* Rostering
* Schedule uploads
* Validation and publishing

== Important Information

* The current registration is the official source of truth for league participants.
* League coordinators must roster participants from the current registration.
* Do not use prior-year rosters as the source of truth for the current season.
* Historical teams, rosters, schedules, standings, and game results are considered permanent records.
* League setup activities should never modify historical records.

== League Setup Overview

The standard workflow is:

. <<Registration, Export Registration Data (Optional)>>
. Create Fall/Winter/Spring Subseason
. Create Teams
. Roster Players
. Prepare Schedule
. Upload Schedule

=== New Season Steps
.Seasons Tab
image::se_seasons_tab.png[Seasons Tab]

[NOTE]
Additional Step images can seen below in the <<new-season-images, New Season Images>> section.

. Create a new season by clicking the small new season button in the upper right corner of the Seasons tab (see image above).
. <<ns_steps_2_3_4_5, Club/League>>: From the dropdown, select the league for which you are creating a new season.
* If you do not see the league in the dropdown, contact the mailto:leagues@evergreencurling.com[Evergreen Leagues Coordinator] to have the league created.
. <<ns_steps_2_3_4_5, Season Name>>: Enter the year range for the season, e.g. `2026-2027`.
. <<ns_steps_2_3_4_5, Subseason Name>>: Enter the subseason name, e.g. `Fall`, `Winter`, `Spring`.
. <<ns_steps_2_3_4_5, Statistic Grouping>>: Leave as `Regular Season`.
. <<ns_step_6, Custom Points>>: Here you can enter the points for a win, loss, tie, etc.
. <<ns_step_7, Standings View>>: This is where you can select how the standings are displayed, e.g. `Points`, `Wins`, `Losses`, etc.
* Recommend to use `Points`, `Wins`, `Losses`, `Ties`, `Games Remaining` (or `Games Played`).
* Tuesday Competitive leagues may want to use `Points`, `Wins`, `Losses`, `Overtime Wins`, `Overtime Losses`, `Games Remaining`.
. <<ns_step_8, Standings Order>>: Leave as `Default`.
. <<ns_step_9, Data Source>>: Select `Start from scratch` to create a new season with no historical data.
* Using `From League import` or `Copy subseason` will make rostering the teams harder and can affect the historical data for past seasons of the league if rosters are changed.
. <<ns_step_10, Enable Qualifiers>>: Leave unchecked.
. <<ns_step_10, Generate Game ID's>>: Leave as `None`.
. <<ns_step_10, Create Season>>: Press the `Create Season` button to create the new season.

=== Create Team Steps

For each team:

. Click Add Team button on the Teams tab.
. Select `Create a new Team`.
* Using an existing team will copy the roster and historical data from the previous season which is not desired as doing so will make rostering the teams harder and can affect the historical data for past seasons of the league if rosters are changed.
. Top Template: Select `None`
. Bottom Template: Select `None`
. Name: Enter Team Name.
. Short Name: Enter Short Name.
* This is what will be shown on the banner in the Evergreen League Page
image::team_banner.png[Team Banner]
. [[team_abbreviation]]Abbreviation: Enter Abbreviation.
* This is useful for game scheduling.  Recommendation is to keep it 6 characters:
** 2 for the year
** 1 for the league weekday (M, T, W, H, F, S, U)
** 1 for the subseason (F, W, S)
** 2 for the team number.

+
[EXAMPLE]
====
Example: `26HF01` for 2026 Thursday Fall Team 1.
====
. Team Gender: Leave as `Co-ed`.
. Primary Color: Leave defaulted.
. Logo to Upload: Leave unmodified.
. Include Team in Standings: Leave as `Yes`.
. Page Display Status: Select `Public` if available.
* Public will allow hte members rostered to see the team page and the team in SportsEngine app.
. Click Create team Page button

Repeat for all teams.

====
You can create placeholders teams and rename the teams later.

=== [[create-schedule]]Build Schedule File

SportsEngine uses a CSV file to upload the schedule.  The CSV file can be created in Excel or Google Sheets, but must follow the template.

==== Download Schedule Template

You can download the SE Template from SportsEngine, but it has a lot of extra information that is not needed for Evergreen Curling Club leagues.  The link:schedule_template.csv[Schedule Template here] is a simplified version of the SE template and recommended for use by league coordinators.

Below is a what each column in the template is used for and what data should be entered.

Format::
* Tells SportsEngine what import format this CSV is using.
* Value/format: `SportsEngine`
* RECOMMENDATION: Do not change this value.

Start_Date::
* The date the game starts.
* Value/format: `MM/DD/YYYY`, for example `09/24/2026`

Start_Time::
* The start time of the game.
* Value/format: `HH:MM:SS` in 24-hour time, for example `18:00:00`

End_Date::
* The date the game ends. For a single game, this is usually the same as the start date.
* Value/format: `MM/DD/YYYY`, for example `09/24/2026`

End_Time::
* The end time of the game.
* Value/format: `HH:MM:SS` in 24-hour time, for example `20:00:00`

Location::
* The sheet name where the game is played.
* Value/format: sheet name, for example `Sheet A`

Team1_ID::
* The team ID for the first team in the matchup.
* Value/format: assigned team ID, for example `26HF04`

Team2_ID::
* The team ID for the second team in the matchup.
* Value/format: assigned team ID, for example `26HF08`

Description::
* Optional text describing the event or notes for the game.
* Required by SportsEngine for importing, so it cannot be removed from the csv.
* RECOMMENDATION: Leave blank as this is not used by Evergreen Curling Club leagues.

Location_Url::
* Optional URL for the playing location or venue.
* Required by SportsEngine for importing, so it cannot be removed from the csv.
* RECOMMENDATION: Leave blank as this is not used by Evergreen Curling Club leagues.

Location_Details::
* Optional notes about the venue or location.
* Required by SportsEngine for importing, so it cannot be removed from the csv.
* RECOMMENDATION: Leave blank as this is not used by Evergreen Curling Club leagues.

All_Day_Event::
* Marks whether this event is an all-day event.
* Required by SportsEngine for importing, so it cannot be removed from the csv.
* RECOMENDATION: Use '0' for all Evergreen Curling Club leagues as they are not all-day events.

Event_Type::
* Identifies the type of event being imported.
* Value/format: `Game`
* RECOMENDATION: Always use `Game` for Evergreen Curling Club leagues.

Tags::
* Optional tags assigned to the event.
* Required by SportsEngine for importing, so it cannot be removed from the csv.
* RECOMMENDATION: Leave blank as this is not used by Evergreen Curling Club leagues.

Team1_Is_Home::
* Indicates whether Team1 is the home team.
* Value/format: `1` for home, `0` for away
* RECOMENDATION: Always make Team1 the home team for Evergreen Curling Club leagues as it doesn't matter which team is home or away.

Team2_Name::
* This field is not normally used for a standard league schedule import, but required by SportsEngine.
* Required by SportsEngine for importing, so it cannot be removed from the csv.
* RECOMMENDATION: Use `0` for all Evergreen Curling Club leagues as they are not used.

Custom_Opponent::
* Indicates whether the matchup is a custom opponent entry instead of a regular league game.
* Required by SportsEngine for importing, so it cannot be removed from the csv.
* RECOMMENDATION: Use `FALSE` for league games

=== Common Problems

=== Schedule Imported Incorrectly

* Use the override option carefully.
* If you support multiple leagues, this button can delete unintended games from unaffected seasons.

* Best known practice is to export the csv and update the data leaving the game ID unchanged.

==== All games on the same date

* Root cause is incorrect return character.
** If exporting from Excel, be sure to save it as _????_

== Fixing an Imported Schedule

[IMPORTANT]
====
If you need to fix an imported schedule, do not delete the games and re-import.
====

It is easiest to export the schedule to a csv, make the changes, and re-import the schedule.  The game ID's will remain the same and the unintended data will not be removed.
